# 실측 비등곡선 Cooper 게이트

- 입력: `data/experiments/zimmermann2020_fc72_smooth.csv`, `data/experiments/mudawar1990_fig7_digitized.csv`, `data/experiments/parker2008_fig4_14a_digitized.csv`
- 평가 구간: 상승 측정, q ≥ 20 kW/m², q ≤ 80% × 곡선 최대 q (판단값, 아래 민감도 표)
- Cooper: R_p = 1.0 µm 고정, 곡선마다 그 압력의 p_r
- 기준: 곡선마다 MAPE ≤ 30%, log-log 기울기 0.33 ± 0.05, 구간 안 점 5개 이상. 실측 곡선은 사이트 수가 물리로 정해지므로 기울기도 판정 기준이다.

### 곡선별 — 구간을 바꿔도 판정이 같은가
